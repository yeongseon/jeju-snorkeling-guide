# 제주 스노클링 가이드 (교육용 시제품)

HRA 19기 2조의 「제주 초행자를 위한 제주 스노클링 가이드북」을 바탕으로 만든 정적 웹서비스다. HRA 20기 바이브코딩 수업에서 PRD → UX/UI → 구현 → 확인 → 배포를 실제 화면으로 보여 주기 위한 기준 버전이다.

- 공개 사이트: https://yeongseon.github.io/jeju-snorkeling-guide/
- 코드 저장소: https://github.com/yeongseon/jeju-snorkeling-guide

## 실행

Node.js 설치 후 이 폴더에서:

```bash
npm ci
npm run dev
```

터미널에 표시되는 `localhost` 주소를 브라우저에서 연다. 검증 및 빌드는 `npm test`, `npm run build`로 실행한다. 정적 결과물은 `dist/`에 생성된다.

## 시연 경로

1. 첫 화면에서 '여섯 장소 살펴보기'를 누른다.
2. 6곳 목록과 지역 필터, 이름 검색을 확인한다.
3. '현장 대여' 조건을 고르면 미확인 정보를 근거로 장소를 추천하지 않는 빈 결과가 나온다. 조건을 지우고 판포포구 상세를 연다.
4. '준비' 탭에서 체크박스를 선택하고 새로고침 후 상태가 유지되는지 본다. 저장은 **같은 브라우저**에만 적용된다.
5. '안전' 탭에서 실시간 안전 판정이 없고 현지·공식 정보 확인을 권하는지 살핀다.

## 데이터와 공개 범위

PDF 4쪽에서 6곳의 표기와 지역만 가져왔다. PDF 6~7쪽의 판포포구 대여·샤워 가격·교통 시간·안전요원 기간은 검증하지 않았으므로 사이트에 확정 사실로 게시하지 않았다. 다른 5곳의 장소별 시설 데이터도 없다. 추상 색면은 실제 장소 사진이 아니다. PDF 파일과 표지의 개인 이름은 프로젝트에 복사하지 않는다.

## 배포

`main`에 push하면 `.github/workflows/deploy.yml`이 테스트 → 빌드 → GitHub Pages 배포를 실행한다(`Settings → Pages → Source: GitHub Actions`). Pages는 정적 파일만 호스팅한다. 이 서비스에는 서버, 로그인, 결제, 실시간 해양 정보가 없다.
